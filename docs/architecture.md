# CodeScope 第一版架构

## 已确定的产品边界

独立实现，以源码与文档为依据探索业务数据关系。用户手动触发扫描，不监听工作区、不注册 Git hooks、不使用 Webhook。解释语言来自被扫描仓库文档，可由用户覆盖。当前实现以 TS/JS 的函数级静态调用关系为起点；完整数据流分析是后续能力，不能从调用图直接宣称得到。

## 数据流

```text
浏览器触发扫描 → 本地 API → 独立扫描进程
                                ↓
         文件清单 / 内容哈希 / 文档语言 / AST / 符号解析
                                ↓
                 节点 + 带源码位置的关系 + 限制
                                ↓
                 SQLite 最新成功快照 → Web 图谱

用户主动生成解读 → 相关子图 + 源码摘录 + 文档 + 输出语言
                                ↓
                  模型适配 → JSON / 引用校验
                                ↓
                解读缓存 → AI 解释与节点业务标签
```

## 分层

- `server/scanner.ts`：只读遍历、内容差异、AST 复用、符号/调用/导入/路由候选。构建 CompilerHost 时仅允许读取扫描清单中的源码。
- `server/worker.ts`：独立进程执行扫描；进度通过 IPC 传给服务，防止扫描占用 API 主线程。
- `server/store.ts`：保存完整扫描快照与解读缓存。成功扫描才替换旧记录。
- `server/app.ts`：仓库、任务、源码快照、模型设置、解释接口。仅接受本机 Host 和同源请求。密钥不会从配置接口返回。
- `server/llm.ts`：兼容 API 适配、邻域上下文构建、输出验证、模型错误隔离。只接受 HTTPS 远程地址或 HTTP 回环地址。
- `shared/types.ts`：证据图契约与有向路径查询。
- `src/Graph.tsx`：与分析无关的布局、SVG 呈现、缩放、平移、节点拖动和路径播放。
- `src/App.tsx`：扫描状态、仓库导航、搜索、源码、文档和解释交互。

## 图谱语义

节点保留原始符号、文件、行号、模块和签名。边区分 `calls`、`imports`、`handles`。`handles` 是框架注册形式的候选，不伪装为编译器确认的业务数据传播。嵌套回调有独立节点，避免把回调体调用直接归到外层函数。

AI 不创建或修改事实边。业务解读属于单独记录，带模型、语言、生成时间和引用节点；只校验引用有效性，不声称模型解释已被证明正确。语言改变不会重扫源码。

## 增量策略

文件哈希检测所有代码和文档变化，包括未提交内容。无变化直接复用快照；变化时复用内存中的未变化 AST，然后重新建立关系，避免删除、导入变化导致旧边残留。这是解析复用与全图关系重算，尚不是受影响子图的最小增量分析。保留 UI 的手动语言覆盖。

## 历史：单入口业务流程实现（保留兼容）

默认视图改为业务场景列表及单场景流程图。底层调用图保留在「代码证据」，函数和文件不再作为业务主图节点。新增 `BusinessFlow` 独立契约：入口、处理、判断、结果/未知结束；步骤输入输出；边上条件与数据；源码和文档引用。

`server/business.ts` 从路由及无入边函数识别入口候选，收集下游代码与文档，再调用模型提炼业务流程。模型应读取源码控制逻辑，不得将调用边直接当作先后顺序。校验唯一入口、终点、全图可达性、分支标签、有效引用，并拒绝无出口循环。所有业务连线仍属于 AI 推导，不能宣称已确认的运行时路径。

`src/BusinessFlow.tsx` 展示自上而下的业务步骤和分支，点击步骤后才展开代码证据。业务图独立存储，按快照、语言和模型失效；重新解读失败保留旧结果。业务入口候选不是已经识别完成的业务场景；没有模型时提示配置，不用调用图冒充业务图。

## 当前默认：业务知识图谱

`server/knowledge.ts` 从仓库多个文件轮流选取代码片段及业务文档，生成独立 `BusinessKnowledge`：业务域、参与者、处理环节、数据对象、存储、结果，以及携带业务数据的有向关系。主图不直接映射函数；同一业务目的的多个实现应聚合，共享对象应去重。模型推断不改变底层代码事实图。

`GET/POST /api/knowledge` 读取缓存或显式生成。缓存包含仓库指纹、语言、模型及 API 地址，保存到独立 SQLite 表；更新失败保留旧结果。证据有数量与长度限制，并记录覆盖范围。校验结构、端点、归属、引用和读写方向；语义仍需人工复核。

`src/KnowledgeGraph.tsx` 默认聚合业务域间已有关系。展开域后展示本域实体及一跳跨域实体，共享对象只显示一次。节点/边详情支持引用跳转；点击节点高亮流入、流出或全部相邻关系。SVG 画布默认 100% 缩放，下限 75%，通过拖动与滚动探索较大范围，不自动 fit-all。旧单入口流程接口及缓存保留，主界面不再使用。
